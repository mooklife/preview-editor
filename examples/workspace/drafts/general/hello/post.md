이 글은 **Preview Editor** 샘플 초안입니다. 왼쪽 목록에서 열어 바로 편집해 보세요.

## 해 볼 것

- 본문을 고치고 `⌘S`(또는 `Ctrl+S`)로 저장 → `post.md`가 갱신됩니다.
- 「이미지」 버튼이나 드래그·드롭으로 사진을 넣으면 같은 폴더의 `images/`에 복사됩니다.
- 상단 카테고리를 바꾸면 frontmatter `wp_category`에 기록됩니다.
- `.env`에 WordPress 자격증명을 넣으면「WP draft」/「WP publish」로 바로 올릴 수 있습니다.

> 원본은 언제나 디스크의 Markdown 파일입니다. 에디터는 보이는 대로 편집하는 창일 뿐입니다.

| 항목 | 값 |
| --- | --- |
| 저장 | Markdown + frontmatter |
| 발행 | WordPress REST (draft / publish) |
